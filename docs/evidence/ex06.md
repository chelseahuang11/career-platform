| Record | Name | Value | What it does |
|---|---|---|---|
| MX | `chelseahuang.me` | `mx.zoho.com` 10, `mx2.zoho.com` 20, `mx3.zoho.com` 50 | Other mail servers look this up to find where to deliver `@chelseahuang.me` mail. Lowest number first; the others are backups. |
| SPF (TXT) | `chelseahuang.me` | `v=spf1 include:zohomail.com ~all` | Lists the servers allowed to send as my domain: Zoho's. A receiver compares the sending server's IP with this list. `~all` = anything else is suspicious (soft fail). |
| DKIM (TXT) | `zmail._domainkey.chelseahuang.me` | `v=DKIM1; k=rsa; p=…` | The public key. Zoho signs each outgoing message with the matching private key; the receiver checks the signature, so it knows the message came from my domain and wasn't changed. |
| DMARC (TXT) | `_dmarc.chelseahuang.me` | `v=DMARC1; p=none; rua=mailto:chelsea@chelseahuang.me` | Tells receivers that SPF or DKIM must pass **for the same domain as the From address**, and what to do if not. `p=none` = only report for now; reports go to my Zoho mailbox. |

### Why the click event is useful, and how it gets to Google (added 2026-10-25)

**The action.** I opened https://chelseahuang.me/, accepted analytics, and clicked the GitHub and LinkedIn links in the Contact section. **The events.** Realtime showed one `page_view` and two `click` events. Each `click` carried `link_url`, `link_domain`, and `outbound` (true).

**Why `click` matters for this site.** The site exists to send recruiters on to my real work and contact points. A page view only says someone arrived; an outbound click on GitHub, LinkedIn or a project link says they cared enough to go further, and `link_url` says which. Comparing clicks per link tells me which project or profile draws interest. I didn't write code for it: GA4's Enhanced Measurement "Outbound clicks" option sends `click` with `outbound=true` on its own, so seeing that event with `outbound` set shows the option is on.

**How it travels.** (1) The browser loads my page from Railway. (2) The page loads `gtag.js` from `www.googletagmanager.com`. (3) Consent Mode starts with `analytics_storage: denied`; after the visitor clicks Accept, `gtag` is allowed to set the `_ga` cookies. (4) On page load and on each outbound click, `gtag.js` sends an HTTPS request from the visitor's browser straight to Google Analytics (`…google-analytics.com/g/collect`) with measurement ID `G-R24K9LD7H4`, the event name and its parameters. My server is never in that path; Railway only served the HTML. (5) GA4 processes the hit and shows it in Realtime within seconds.

**What my check shows, and what it doesn't.** It shows the tag loads, consent works, and both a page view and an outbound click reach my GA4 property. It does not show that the standard (non-Realtime) reports are complete, and visitors who decline or block the tag are not counted.
